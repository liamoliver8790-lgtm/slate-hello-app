# slate-hello-app

A minimal Next.js app for Catalyst Slate: a server-rendered page, a client counter, and an API route at `/api/hello`.

## Deploy on Slate
1. In the Catalyst console (console.catalyst.zoho.com), open Slate and create an app from this GitHub repo.
2. Framework: **Next.js**. Root directory: `/`. Build command: `npm run build`.
3. Deploy.

## Run locally
```bash
npm install
npm run build && npm start
```
